
# Application de Traduction Multilingue avec Système Vocal

Cette application permet de traduire des textes dans plusieurs langues et offre également un système vocal pour écouter les traductions.

## Fonctionnalités

- Traduction de textes dans diverses langues.
- Système vocal pour écouter la traduction dans la langue cible.
- Interface simple et facile à utiliser.

## Langues supportées

- Anglais
- Français
- Espagnol
- Allemand
- Italien
- Et bien d'autres...

## Installation

1. Clonez ce repository :
   ```bash
   git clone https://github.com/Rodhackgang/TRADUCTION.git
   ```

2. Installez les dépendances :
   ```bash
   npm install
   ```

3. Lancer l'application :
   ```bash
   npm start
   ```

## Utilisation

- Entrez un texte dans la langue source.
- Sélectionnez la langue cible.
- Cliquez sur le bouton de traduction pour afficher la traduction.
- Cliquez sur le bouton "écouter" pour entendre la traduction.
