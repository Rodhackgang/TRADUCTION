## Présentation

Traducteur web : saisie d'un texte, choix des langues, traduction immédiate.

**Pourquoi ce choix.** Un besoin simple mérite une page simple, sans compte ni installation.

---

## Ce que fait le projet

- Choix de la langue source et cible
- Traduction à la volée
